# Протоколы замеров

Все числа в корневом README взяты отсюда. Файлы — это неотредактированный
вывод программ, а не пересказ: если в таблице стоит 4.4324, в соответствующем
логе видно, из каких прогонов по зёрнам это среднее получилось.

Держать их в репозитории пришлось по простой причине: каталог `data/` в
`.gitignore` (там корпус и чекпоинты), и протоколы жили только на машине, где
считались. Утверждение, за которым не стоит воспроизводимого протокола, —
просто утверждение.

## Абляции

| файл | что считалось |
|---|---|
| `ablate_2seeds_first9.log` | первая таблица: нормировка, позиции, FFN, головы, связывание эмбеддингов — 9 вариантов, 2 зерна |
| `ablate_2seeds_matched_ffn.log` | контрольный вариант к развязыванию эмбеддингов: те же лишние веса, потраченные на ширину FFN |
| `ablate_2seeds_qk_zloss.log` | QK-норма, Z-loss и оба вместе |
| `ablate_2seeds_zloss_x100.log` | Z-loss со стократным коэффициентом — контроль «дело в приёме или в дозе» |
| `seeds6_group_a.log` | шесть зёрен: нормировка, FFN с GELU, обучаемые позиции |
| `seeds6_group_b.log` | шесть зёрен: позиции, MHA, MQA, несвязанные эмбеддинги |
| `seeds6_group_c.log` | шесть зёрен: QK-норма, Z-loss, широкий FFN |

Группы A, B и C — один и тот же замер, разложенный на три процесса ради
параллельности; базовый вариант считается в каждой, потому что он точка отсчёта
для парных разностей.

## Как воспроизвести

Словари BPE лежат в `data/*.bpe` и версионируются — без них числа не
воспроизвести — а корпус скачивается отдельно, см. корневой README.
